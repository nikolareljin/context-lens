# Download

[Latest release](https://github.com/nikolareljin/context-lens/releases/latest){ .md-button .md-button--primary } [All releases](https://github.com/nikolareljin/context-lens/releases){ .md-button }

## Install

1. Download `contextlens-<version>.apk` from the release page on the phone.
2. Allow installs from the browser or file manager when Android asks.
3. Open ContextLens.

Requirements: Android 8.0 (API 26) or newer. The on-device gatekeeper needs a phone with Gemini Nano support (for example recent Pixel and Galaxy flagships). On other phones Strict mode filters with local rules only, and Balanced mode can use the cloud.

!!! note "Before the first release"
    No release has been published yet. Until then, each CI run that builds the app keeps a debug APK as a workflow artifact for 14 days (Actions tab, signed-in GitHub users).
